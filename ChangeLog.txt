VapourSynth Multi-Viewer Change Log

v1.4
- Greatly enhanced text editor with ScriptAssist
- Added Functions Explorer
- Add start page when no document is open
- Ask save confirmation when closing document
- Redesigned application icon
- Redesigned toolbar icons
- Redesigned scrollbars
- Fix horizontal scrollbar page-right
- Reviewed keyboard shortcuts and improved Help documentation
- Check for updates

v1.3
- Enhanced text editor with auto-complete and plugin parameters information, for both VapourSynth and AviSynth
- '-' and '=' characters are no longer being eaten by the editor
- Add spacing in editor after line numbers
- Dark mode is less dark
- Redesigned seek bar

v1.3 (2026-09-16)
- Enhanced text editor with auto-complete and plugin parameters information, for both VapourSynth and AviSynth
- '-' and '=' characters are no longer being eaten by the editor
- Add spacing in editor after line numbers
- Dark mode is less dark
- Redesigned seek bar

v1.2 (2026-09-15)
- Fix AviSynth frame display bug
- Display video/frame properties (Ctrl+I)
- Show detected AviSynth and VapourSynth versions in Settings

v1.1 (2026-09-13)
- Fixed AviSynth/VapourSynth frame display for all pixel formats and bit depths
- Fixed an AviSynth display bug
- Allow tab re-ordering
- Added tab colors to differentiate types
- Allow customizing tab color with Ctrl+T
- Added browse buttons for settings paths
- Tweaked default tab numbering
- Remember window size and maximized state

v1.0 (2026-09-12)
- Cross-platform support (Windows x64/x86, Linux x64/ARM64, macOS Intel/Apple Silicon)
- Both VapourSynth and AviSynth support
- Auto-detection of library and plugin paths across platforms
- Light/Dark theme
- Drag tabs to reorder; Alt+Left/Right moves the current tab; Ctrl+1-9 selects by strip order
- New, Open, and Run always add a tab at the end of the strip
- Auto-numbered Script and Viewer titles continue after the highest open number
- Subtle tab colors mixed from VapourSynth green and AviSynth blue for light and dark themes
- Added copy frame to clipboard
- Fixed many bugs

v0.9.3 (2018-07-26)
- Fixed multi-threading mode not activating
- Added option to display square pixels when zooming

v0.9.2 (2018-07-14)
- Fixed numeric keys not working in editor

v0.9.1 (2018-07-11)

- Enlarged script font

v0.9 (2018-07-09)

- Allow several script editor tabs
